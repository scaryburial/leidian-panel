# 雷电面板（ui3344）

基于 [3x-ui](https://github.com/MHSanaei/3x-ui) 深度定制的 Xray 面板 —— **全中文界面、开箱即用、注重隐私与易用性**。
本仓库为本定制版的**源码与发布仓库**（非原版 3x-ui）。

> 仅供个人学习与自用。请遵守你所在地区的法律法规。

---

## ✨ 主要特性

- **全中文界面**：菜单、提示、文档均为中文。
- **开箱即用**：安装后自动创建 **9 个预设协议**（VLESS / VMess / SS2022 各 速度/安全/综合），无需手动添加。
- **一键分享/订阅**：每个客户端独立订阅链接，弹窗含 **原始 / JSON / Clash** 订阅与二维码，兼容小火箭、Clash/Mihomo、v2rayN 等；Clash 订阅**内置离线分流规则**（广告拦截 + 国内直连 + 其余代理）。
- **出口中转**：「中转」菜单可把客户端流量从上游 **SOCKS5 / HTTP** 出网，支持多条上游分别绑定不同客户端/入站，可写备注。
- **反向代理**（Xray VLESS reverse）：家里无公网 IP 时，让家里机器反连面板，客户端经**家里网络**出网；已为**域名 + Cloudflare 代理**预留（WS+TLS 时自动设置 SNI/Host）。
- **客户端在线 IP / 归属地**：离线也保留最后在线 IP 与归属地；内网/未知有区分。
- **客户端命名友好**：可填中文昵称，系统自动生成内部标识，昵称存备注。
- **内核离线切换**：内置 3 个 Xray 内核版本，离线切换。
- **隐私**：去除公网 IP 探测 / 面板更新检查 / 版本列表联网。
- **界面**：登录页定制背景，面板半透明 + 毛玻璃，侧边栏科技化。

## 🚀 一键安装（推荐）

在服务器上以 **root** 执行：

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/scaryburial/leidian-panel/main/install.sh)
```

脚本会自动：下载最新发布包 → 校验 sha256 → 解压安装 → 创建预设协议 → 配置订阅服务。

## 📦 手动安装

1. 到 [Releases](https://github.com/scaryburial/leidian-panel/releases/latest) 下载 `ui3344-linux-amd64.tar.gz` 与 `.sha256`；
2. 校验：
   ```bash
   sha256sum -c ui3344-linux-amd64.tar.gz.sha256   # 或手动比对
   ```
3. 解压安装（需 root）：
   ```bash
   tar xzf ui3344-linux-amd64.tar.gz
   cd ui3344
   bash install.sh
   ```

## 🔌 预设协议端口

| 协议 | 端口 | 说明 |
|---|---|---|
| VLESS | 8443 | 速度（TCP） |
| VLESS | 443 | 安全（Reality） |
| VLESS | 2087 | 综合（WebSocket） |
| VMess | 8080 | 速度（TCP） |
| VMess | 2053 | 安全（TLS 自签） |
| VMess | 2052 | 综合（WebSocket） |
| SS2022 | 8388 | 速度（aes-128-gcm） |
| SS2022 | 8389 | 安全（aes-256-gcm） |
| SS2022 | 8390 | 综合（aes-256-gcm） |

订阅端口：**2096**（记得在安全组放行）。

> ⚠️ 使用 **SS2022 多用户**时，同一客户端不要同时挂到「密钥长度不同」的入站（如 aes-128 与 aes-256），否则 Xray 会因密钥不合法启动失败。

